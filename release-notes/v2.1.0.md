## Downloads

| Your computer | Download |
|---|---|
| Windows | `doki-Windows-x64.zip`: extract the folder and run **doki.exe** |
| Mac with Apple Silicon (M1 or newer), macOS 14+ | `doki-macOS-arm64.zip` |
| Mac with an Intel chip, macOS 15+ | `doki-macOS-intel.zip` |

**Mac:** unzip, move **doki.app** to Applications, then run this once in Terminal, because doki isn't signed with an Apple developer certificate:

```sh
xattr -dr com.apple.quarantine /Applications/doki.app
```

## What's new

- **Subtitles in any language.** The Subtitles list now shows every track doki finds, labelled by language (Spanish, French, Japanese, Kurdish and about 30 more), not only English. doki remembers the language you pick and selects it again next time.
- **Watch progress in Recently watched.** Each episode shows how far you got (*12:34 / 23:40*) or *✓ watched*. Pick one and press **✕** to remove it from your history.
- **Update notices.** From now on, doki tells you when a new version is out and links to the download. Because this is the first version with the check, you have to download 2.1.0 yourself.
- **More reliable builds.** doki now ships the official mpv 0.41.0 on both Windows and Mac.
