doki 2.0 bundles everything it needs and now runs on Mac too.

## Downloads

| Your computer | Download |
|---|---|
| Windows | `doki-Windows-x64.zip`: extract the folder and run **doki.exe** |
| Mac with Apple Silicon (M1 or newer), macOS 14+ | `doki-macOS-arm64.zip` |
| Mac with an Intel chip, macOS 15+ | `doki-macOS-intel.zip` |

**Mac:** unzip, move **doki.app** to Applications, then run this once in Terminal, because doki isn't signed with an Apple developer certificate:

```sh
xattr -dr com.apple.quarantine /Applications/doki.app
```

Or right-click doki.app → **Open** → **Open**.

## What's new

- **No setup needed.** mpv and the Anime4K shaders come with doki, so you no longer need to install mpv or edit an `mpv.conf`.
- **Anime4K presets.** *Auto* picks the mode from the stream's resolution: A+A for 1080p, B for 720p, C for lower. You can also pick any mode in HQ or Fast. In the player, `Ctrl+1`–`Ctrl+6` switch modes and `Ctrl+0` turns them off. A+A is GPU-heavy, so pick Mode A or a Fast preset if playback stutters.
- **Fewer windows.** doki looks for the stream in a hidden browser and only shows it if you need to press Play. mpv opens without a console window.
- **Ads and popups blocked** while doki looks for the stream.
- **Recently watched**, a **Next episode** button and **resume** from where you stopped.
- Your quality, subtitle, buffering and Anime4K choices are remembered, and a copied episode link is pasted in when doki opens.
- **Mac support** (new).
